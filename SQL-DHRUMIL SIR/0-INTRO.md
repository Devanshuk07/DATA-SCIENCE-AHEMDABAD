Data must be stored in tables format&#x09;Tables have rows and columns.2\. Data should follow a defined structure (schema)&#x09;Columns have defined data types like INT, VARCHAR, DATE, etc.5\. Data integrity is maintained&#x09;Rules like PRIMARY KEY, FOREIGN KEY, NOT NULL, UNIQUE, CHECK, etc. help keep data valid.6\. Uses SQL&#x09;SQL is used to insert, update, delete, and retrieve data.7\. acid property.(if all this rules are followed then it is rdbms database).//query - 1)database - 2)table -data.(you can store multiple table in 1 database).
