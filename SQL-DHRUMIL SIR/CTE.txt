Suppose we have:
employee
-------------------------
emp_id | emp_name | salary
1      | Rahul    | 50000
2      | Amit     | 70000
3      | Priya    | 90000

*We want employees whose salary is greater than 60000:

WITH high_salary AS (                                      
    SELECT *
    FROM employee
    WHERE salary > 60000         ----> THIS IS QUERY
)
SELECT *
FROM high_salary;                ---> THIS IS MAIN QUERY

Result:

emp_id | emp_name | salary
2      | Amit     | 70000
3      | Priya    | 90000
-------------------------------------------------------------------------
Why use CTE?

CTEs mainly make complex queries easier to read and manage.
CTE = Give a name to a temporary query result and use that name later in the same query.


Basic syntax:-

WITH cte_name AS (
    SELECT *
    FROM employee
)
SELECT *
FROM cte_name;

Think of it as:

First create a temporary result → then use that result in the next query.
